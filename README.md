# QuickPlace — быстрая установка блоков (Fabric 1.21.11)

Клиентский мод: пока зажата ПКМ с блоком в руке, блок ставится **сразу**, как только прицел
перешёл на новое место — без ванильной задержки в 4 тика. Работает на серверах.

- **V** (Управление → «Разное») — включить/выключить быструю установку блоков.
- Безопасный край отключён: мод не останавливает игрока, поэтому при движении можно упасть.

Внимание: на серверах с античитом такие функции могут быть расценены как читерство. Используйте в одиночной игре или на своих серверах.

## Требования
- Minecraft 1.21.11, Fabric Loader 0.20.1+, Fabric API
- Java 21

## Сборка
```
./gradlew build          # Linux / macOS
gradlew.bat build        # Windows
```
Готовый jar: `build/libs/quickplace-1.0.0.jar` (без `-sources`).
Положите его в папку `mods/` вместе с Fabric API.

Тестовый запуск: `./gradlew runClient`
(первая сборка скачивает и подготавливает Minecraft — нужно несколько минут и достаточно RAM, рекомендуется 4+ ГБ).

## Как устроено
- `QuickPlaceClient.java` — каждый тик проверяет, куда смотрит игрок. Если цель сменилась
  и зажата ПКМ с блоком, сбрасывается счётчик `rightClickDelay`, и ванилла ставит блок в этом же тике.
- `mixin/MinecraftAccessor.java` — mixin-доступ к приватному полю `rightClickDelay`.
